#+TITLE: Neoarch Emacs User Manual

Press =C-x x= inside Emacs to display this cheat sheet at any time.

* Keybinds

** Projects & Perspectives

|---------------------+---------------------------------+---------------------------|
| Keybind             | Action                          | Command                   |
|---------------------+---------------------------------+---------------------------|
| s-j                 | Switch perspective              | neoarch/project-switch    |
| s-1 .. s-9          | Switch perspective by number    | persp-switch-by-number    |
| C-<tab> / C-S-<tab> | Next / previous perspective     | persp-next / persp-prev   |
| s-o                 | Open project in new perspective | neoarch/project-open      |
| s-n                 | Create project                  | neoarch/project-create    |
| s-q                 | Close project perspective       | neoarch/project-close     |
| s-w                 | Close current buffer            | kill-current-buffer       |
| C-x p               | Projectile command prefix       | projectile-command-map    |
|---------------------+---------------------------------+---------------------------|

** Windows

|------------+---------------------------+------------------------------|

| s-<arrows> | Focus window in direction | windmove-left/right/up/down  |
|------------+---------------------------+------------------------------|

** Files & Search

|---------+---------------------------------------+-------------------------------|
| Keybind | Action                                | Command                       |
|---------+---------------------------------------+-------------------------------|
| s-p     | Find file in project                  | neoarch/project-find-file     |
| s-f     | Ripgrep in project                    | neoarch/project-grep          |

|---------+---------------------------------------+-------------------------------|

** Terminal

|---------+---------------------------------------+-----------------------------------|
| Keybind | Action                                | Command                           |
|---------+---------------------------------------+-----------------------------------|
| s-t     | Toggle project terminal (C-u: new)    | neoarch/project-terminal          |
| C-`     | Toggle project terminal               | neoarch/project-terminal          |
| s-`     | Switch to any terminal buffer         | neoarch/switch-to-terminal-buffer |
| C-c C-k | Toggle vterm passthrough (in vterm)   | neoarch/vterm-toggle-passthrough  |
|---------+---------------------------------------+-----------------------------------|
